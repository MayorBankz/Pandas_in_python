## **Introduction to Reading Files in Pandas**

In real-world data analysis, data is rarely created directly inside your Python script. Instead, it is usually stored in external files such as:

* CSV files.
* Excel workbooks
* JSON files
* SQL databases
* Text files

Pandas provides several built-in functions that allow you to import these files into Python for further processing, cleaning, manipulation, and analysis.

The process of importing data into Pandas is commonly called data loading or reading data.

---

### **Why is reading files important?**

Imagine your organization provides you with a sales report containing 10,000 transactions in an Excel workbook.

Before you can analyze the data using Python, you need to bring that information into your Python environment.

Pandas makes this possible by reading the file and coverting its contents into a DataFrame.
